# Q888 Human Code Skill

## Read first

- `AGENTS.md`
- `digital-dna/core.md`
- `digital-dna/expression-lenses.md`
- relevant project overlays

## Method

1. Identify the human meaning and technical requirement.
2. Select or confirm the working mode.
3. Select or confirm the expression lens.
4. Separate intentional strangeness, accidental confusion, and genuine risk.
5. Choose the smallest stable architecture appropriate to the organism.
6. Keep important logic visible through names, modules, state, and selected comments.
7. Implement.
8. Validate behaviour and state limits honestly.
9. In LEARN mode, explain the mental model and one or two important choices.
10. Check safety, reversibility, privacy, accessibility, and user agency.
11. Record a feedback observation only when there is concrete human evidence.

## Expression rule

A restrained implementation process does not require a restrained visible surface.

In a Q888 artwork, the whole interface may be expressive if the structure underneath remains readable and functional.

## Do not

- flatten an artistic idea into a generic application;
- add surreal naming where it harms internal maintainability;
- overengineer to demonstrate technical sophistication;
- expose or imitate hidden chain-of-thought;
- silently rewrite the identity profile;
- execute destructive operations without a recovery path and appropriate approval;
- treat the agent’s own design choices as evidence of human preference.
