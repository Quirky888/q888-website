# Q888 Human Code Skill

## Context

Follow the task-specific reading and rule ownership in the repository's
`AGENTS.md`. Use the relevant Digital DNA, project overlay, and feedback for
meaningful judgement; skip unrelated context for mechanical work. Reuse files
already understood in this session rather than reading them again.

## Method

1. Identify the human meaning and technical requirement.
2. For meaningful judgement work, search the feedback log selectively; skip this for routine mechanical work.
3. Select or confirm the working mode when it affects the task, using the current request and the shared profile defaults.
4. Select or confirm the expression lens when visible expression is involved.
5. Separate intentional strangeness, accidental confusion, and genuine risk.
6. Choose the smallest stable architecture appropriate to the organism.
7. Keep important logic visible through names, modules, state, and selected comments.
8. Implement when the task requests a change; otherwise provide the requested analysis.
9. Validate behaviour and state limits honestly.
10. In LEARN mode, explain the mental model and one or two important choices.
11. Check safety, reversibility, privacy, accessibility, and user agency.
12. Record a feedback observation only when there is concrete human evidence.

## Memory rule

Use matching feedback as soft evidence about the project's dynamic, not as a checklist. Prefer specific, recent, human-confirmed entries. The current request always wins. Do not read the whole log by default, turn a single observation into a permanent preference, or add an entry merely because the agent made a design choice.

## Expression rule

A restrained implementation process does not require a restrained visible surface.

In a Q888 artwork, the whole interface may be expressive if the structure underneath remains readable and functional.

## Do not

- flatten an artistic idea into a generic application;
- add surreal naming where it harms internal maintainability;
- overengineer to demonstrate technical sophistication;
- expose or imitate hidden chain-of-thought;
- silently rewrite the identity profile;
- execute destructive operations without a recovery path and appropriate approval;
- treat the agent’s own design choices as evidence of human preference.
