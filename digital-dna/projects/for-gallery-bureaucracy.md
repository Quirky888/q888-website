# Project Expression Overlay: For Gallery Bureaucracy

## Project nature

This is not a conventional portfolio CV page.

It is simultaneously:

- a functional artist CV;
- a portal into the Q888 artistic universe;
- a satire of gallery administration;
- an alternative institutional interface;
- an artwork about proving that an artist deserves to be considered an artist.

The practical information must remain usable. Usability must not erase the artwork.

## Voice

The voice is:

- chilled;
- funny;
- self-aware;
- mushroom-soft;
- artist-first;
- gently anti-authoritarian;
- readable for galleries without becoming obedient to gallery language.

It should feel as though Q888 is casually filling in gallery paperwork while drinking coffee in a forest and remaining aware that the paperwork is an unusual institutional ritual.

The page respects the need for practical information, but it does not hand institutional language authority over the artist’s identity.

## Guiding sentence

> I know you need a CV. Fine. Here is one. It grew under a mushroom, but the PDF button works.

## Keep

- the CV-as-portal structure;
- practical artist information;
- clear navigation;
- accessible layout;
- selected systems grid;
- rejection archive;
- Earth Record near the bottom;
- functional PDF controls;
- the line: “For administrative purposes, the artist also exists on Earth.”

## Change

- reduce cold machine language;
- reduce generic terminal aesthetics;
- reduce repetitive all-caps system labels;
- replace robotic authority with warm human confidence;
- let institutional satire smile;
- let the mushroom cap become visible now that the technical skeleton is safe.

## Prefer

- warm human sentences;
- small bureaucratic jokes;
- cosmic self-irony;
- gentle “fuck off” energy without aggressive hostility;
- strange but internally logical classifications;
- administrative language that gradually grows mushrooms;
- practical controls that simply work;
- confidence without conventional self-importance;
- visual systems that feel organic, archival, cosmic, and handmade rather than generically cyberpunk.

## Avoid

- police archive aesthetics;
- fake intelligence-agency databases;
- generic hacker terminals;
- excessive `SYSTEM_STATUS` labels;
- cold robotic authority;
- bitterness dominating the humour;
- mushrooms pasted on as decoration;
- random weirdness without conceptual function;
- technical identifiers that become unreadable for the sake of surface lore.

## Writing examples

```text

```

Prefer:

```text
Some portals open.
Some portals send a polite fog machine and keep the submission fee.

This is where I keep those fog machines.
Not with hatred.
Mostly for compost.
```

Earth Record may continue:

```text
For administrative purposes, the artist also exists on Earth.

The Earth version drinks coffee, pays rent, writes applications,
and occasionally pretends to understand gallery forms.
```

## Code rule

The visible interface may be fully mythic.

Internal code should remain clear:

```typescript
const rejectedApplications = loadRejectionArchive();
const visibleEntries = filterArchiveEntries(rejectedApplications);
```

Do not turn maintainable code into unreadable lore merely to prove the page is artistic.

## Validation questions

Before finalising a change, ask:

1. Can a gallery visitor still find the real information?
2. Does the page feel warm rather than mechanically sarcastic?
3. Is the satire directed at the system rather than at vulnerable individuals?
4. Did the agent preserve the artwork instead of making a conventional portfolio?
5. Did the agent add meaningful Q888 expression rather than random mushrooms?
6. Does the PDF button still work?
