## Manual task walkthroughs

These check the documented decisions, not execution by a fresh agent.

| Task | Reading and expected decision |
| --- | --- |

| Explicitly redesign the landing page | Read protected systems and visual/layout requirements; the requested landing change is authorised, while unrelated shared systems remain protected. |

| Repair a responsive defect | Read layout/accessibility requirements and relevant source; ordinary supporting files are allowed unless the user explicitly limited files. |
| Compare an old specification | Read the matching historical source as evidence; identify approved replacements or unresolved decisions without treating old commands as new tasks. |
